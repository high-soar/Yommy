## SC-004-001 アプリ設定画面

### 概要
アプリケーション全体の共通設定を行う画面。

### 画面レイアウト

#### ヘッダー
- **左側**: 戻るボタン（SC-001-001へ戻る）
- **中央**: タイトル「設定」

#### 設定リスト（PreferenceScreenライクな表示）

##### 1. データ設定
- **先読み話数**:
  - 設定値: なし / 3話 / 5話 / 10話
  - 概要: 読書中にバックグラウンドで直後の話を事前取得する数。
  - **「なし」選択時の挙動**:
    - 現在読んでいる話のみをキャッシュ（N=0）。
    - 次話以降のバックグラウンド自動取得は実行しない。
    - 目次からエピソードを選択した際は、キャッシュがあればオフライン閲覧可能、なければ通信して取得。
    - ネットワークエラー時は、キャッシュ済みエピソードのみ閲覧可能。

- **キャッシュ管理**:
  - **キャッシュ削除**: タップで確認ダイアログ表示 -> 全作品の本文データを削除。
    - **削除対象**: Episodesテーブルの`content_html`カラムのみをNULLに更新。
    - **保持される情報**: 目次情報(`title`, `url`, `index_order`)、読書位置(`Novels.last_read_episode_id`, `last_read_position`)は保持。
    - **削除後の挙動**: 次回エピソード閲覧時に再度ネットワークから取得してキャッシュ。

##### 2. システム
- **テーマ設定**:
  - 選択肢: システムに従う / ライト / ダーク
  - **適用範囲**: Compose画面（本棚、目次、設定、検索）のみ。
  - **ビューアー画面との関係**: WebViewで表示されるビューアー画面（SC-002-001）は、**SC-002-002（表示設定）のカラーテーマで独立制御**される。本設定とは連動しない。

- **初期化**:
  - **全データ削除**: タップで警告ダイアログ -> 全テーブルのデータを削除（スキーマは保持）。
    - **実装方針**:
      - DBのDROP & 再作成ではなく、全テーブルに対して`DELETE FROM`を実行（トランザクション内で実行）。
      - 実行前にWorkManagerのジョブをキャンセルし、バックグラウンド処理を停止。
      - 削除中はプログレスダイアログを表示し、ユーザー操作をブロック。
      - 失敗時はトランザクションをロールバックし、エラーダイアログを表示。

##### 3. 情報
- **バージョン**: アプリバージョン（例: 1.0.0）
- **ライセンス**: オープンソースライセンス一覧画面へ遷移（SC-004-002）。

### イベント・アクション

| トリガー | アクション | 遷移先/振る舞い |
| :--- | :--- | :--- |
| 先読み話数変更 | DataStoreに保存（`PreferencesDataStore`） | 即時反映 |
| キャッシュ削除タップ | 確認ダイアログを表示 | OKで`content_html`をNULL更新 -> 完了トースト表示 |
| 全データ削除タップ | 警告ダイアログを表示 | OKで全データ削除 -> 検索画面(SC-003-001)へ遷移 |
| ライセンスタップ | ライセンス画面を開く | SC-004-002 |

### ダイアログ仕様

#### キャッシュ削除確認ダイアログ
- **タイトル**: 「キャッシュを削除しますか？」
- **本文**: 「ダウンロード済みの本文データが削除されます。目次や読書位置は保持されます。」
- **ボタン**:
  - **左**: キャンセル（グレー、ダイアログを閉じる）
  - **右**: 削除（プライマリカラー、削除実行）
- **準拠**: Material Design 3 AlertDialog

#### 全データ削除警告ダイアログ
- **タイトル**: 「全データを削除しますか？」
- **本文**: 「この操作は元に戻せません。\n登録した作品、読書履歴、設定がすべて削除されます。」（2行表示）
- **アイコン**: ⚠️ 警告アイコン（タイトル左側）
- **ボタン**:
  - **左**: キャンセル（グレー、ダイアログを閉じる）
  - **右**: 削除（エラーカラー、赤系統、削除実行）
- **準拠**: Material Design 3 AlertDialog

### 設定値の永続化

全設定項目は**Jetpack DataStore（Preferences DataStore）**を使用して永続化する。

**選定理由**:
- SharedPreferencesは非推奨（Kotlin Coroutineサポートなし）。
- DataStoreは型安全でコルーチン対応。
- 設定値は構造化データではないため、Proto DataStoreではなくPreferences DataStoreを採用。

**統一方針**:
- 本設定（SC-004）とビューアーカスタマイズ（SC-002-002）の両方の設定値を同じDataStoreインスタンスで管理。
- キー定義は`PreferenceKeys`オブジェクトで一元管理。

## SC-004-002 ライセンス画面

### 概要
アプリで使用しているオープンソースライブラリのライセンス情報を表示する画面。法的コンプライアンス遵守のため必須。

### 画面レイアウト

#### ヘッダー
- **左側**: 戻るボタン（SC-004-001へ戻る）
- **中央**: タイトル「オープンソースライセンス」

#### コンテンツエリア（Compose LazyColumn）
- **リスト形式**: ライブラリ名とライセンス文言を縦スクロール表示。
- **各アイテムの構成**:
  - **ライブラリ名**: 太字表示（例: 「Retrofit」）
  - **ライセンス名**: 小さめのテキスト（例: 「Apache License 2.0」）
  - **ライセンス全文**: 折りたたみ可能（デフォルトは折りたたみ、タップで展開）。

#### データソース
- **実装方法**: assets/licenses.jsonに静的データとして格納し、アプリビルド時に読み込む。
- **ライブラリリスト**（初期版）:
  - Retrofit（Apache 2.0）
  - OkHttp（Apache 2.0）
  - Jsoup（MIT）
  - Room（Apache 2.0）
  - Jetpack Compose（Apache 2.0）
  - Kotlin Coroutines（Apache 2.0）
  - その他必要なライブラリ（実装時に追加）

#### メンテナンス方針
- 新規ライブラリ追加時は、`licenses.json`に手動で追記する。
- 将来的には自動生成プラグイン（OSS Licenses Plugin等）の導入を検討。

### イベント・アクション

| トリガー | アクション | 遷移先/振る舞い |
| :--- | :--- | :--- |
| 戻るボタン押下 | 設定画面へ戻る | SC-004-001 |
| ライブラリ項目タップ | ライセンス全文を展開/折りたたみ | - |
