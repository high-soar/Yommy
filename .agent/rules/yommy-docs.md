# Web小説リーダー（Fire HD向け） 要件

## 1. プロジェクト概要

* **目的:** 既存アプリ終了に伴う、自分好みのカスタマイズが可能なWeb小説リーダーの自作。
* **ターゲット端末:** Amazon Fire HD（Androidベース）。
* **対応サイト:**
1. **カクヨム**（優先・スクレイピング）
2. 小説家になろう（将来対応）

## 2. システム構成・技術スタック

* **開発言語:** Kotlin
* **UIフレームワーク:** Jetpack Compose（メイン画面）、WebView（閲覧画面）
* **通信・解析:** Retrofit / OkHttp + Jsoup
* **データベース:** Room（ローカル保存・履歴管理）
* **非機能要件:**
* **Fire OS最適化:** 低スペック端末でも軽快に動作すること。
* **スクレイピングマナー:** サーバー負荷を考慮し、User-Agentの設定と過度なアクセスの抑制を行う。
