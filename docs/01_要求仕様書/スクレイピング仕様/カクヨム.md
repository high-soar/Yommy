# カクヨム スクレイピング仕様書

## 1. 基本方針

*   **HTML解析ライブラリ:** Jsoupを使用する。
*   **セレクタ:** 可能な限りIDや意味のあるクラス名（`widget-*`など）を使用し、CSS Modulesのようなランダムなハッシュ値（例: `__ocg9K`）を含むクラス名は、前方一致検索や正規表現、または構造依存（`a`タグ直下の`div`など）で対応する。
*   **待機時間:** 各リクエスト間に**最低3秒以上**のインターバルを設ける（厳守）。
*   **User-Agent:** 適切なUAを設定し、ボットであることを明示しない（通常のブラウザとして振る舞う）。

## 2. ランキングページ

**対象URL:** `https://kakuyomu.jp/rankings/{genre}/{period}`
(例: `https://kakuyomu.jp/rankings/all/weekly`)

### パラメータ定義

#### `{genre}` (ジャンル)
*   `all`: 総合
*   `fantasy`: 異世界ファンタジー
*   `action`: 現代ファンタジー
*   `sf`: SF
*   `love_story`: 恋愛
*   `romance`: ラブコメ
*   `drama`: 現代ドラマ
*   `horror`: ホラー
*   `mystery`: ミステリー
*   `nonfiction`: エッセイ・ノンフィクション
*   `history`: 歴史・時代・伝奇
*   `criticism`: 創作論・評論
*   `others`: 詩・童話・その他

#### `{period}` (集計期間)
*   `daily`: 日間
*   `weekly`: 週間
*   `monthly`: 月間
*   `yearly`: 年間
*   `entire`: 累計

#### クエリパラメータ (任意)
*   `work_variation`: 作品種別
    *   `long`: 長編 (デフォルト)
    *   `short`: 短編
    *   `all`: すべて

### 取得データ一覧

各作品カード（`.widget-work`）から以下の情報を抽出する。

| 項目 | CSSセレクタ / 取得方法 | 備考 |
| :--- | :--- | :--- |
| **作品リスト** | `.widget-work` | リスト要素 |
| **作品ID** | `.widget-workCard-titleLabel` の `href` 属性 | URL末尾の数字列を抽出 |
| **タイトル** | `.widget-workCard-titleLabel` | テキスト |
| **作者名** | `.widget-workCard-authorLabel` | テキスト |
| **あらすじ** | `.widget-workCard-introduction` | テキスト |
| **★評価** | `.widget-workCard-reviewPoints` | "★"を除去して数値化 |
| **ジャンル** | `.widget-workCard-genre a` | テキスト |
| **状態** | `.widget-workCard-statusLabel` | "連載中" / "完結済" |
| **総話数** | `.widget-workCard-episodeCount` | "話"を除去して数値化 |
| **文字数** | `.widget-workCard-characterCount` | "文字"を除去して数値化 |
| **最終更新** | `.widget-workCard-dateUpdated` | "更新"を除去、日時パース |
| **タグ** | `.widget-workCard-tags a span` | リストとして取得 |

## 3. 作品詳細ページ（目次）

**対象URL:** `https://kakuyomu.jp/works/{work_id}`

| 項目 | CSSセレクタ | 備考 |
| :--- | :--- | :--- |
| **作品タイトル** | `#workTitle` | |
| **作者名** | `#workAuthor-activityName` | |
| **キャッチコピー** | `#workCatchphrase` | 存在しない場合あり |
| **あらすじ** | `#introduction` | |

### エピソード一覧（目次）

**HTML構造の注意点:**
目次リストの項目は React/Next.js 等で生成されていると見られ、クラス名にハッシュが含まれる（例: `WorkTocSection_link__ocg9K`）。
そのため、**クラス名の部分一致**または**属性セレクタ**を使用する。

**リストコンテナ:** 特定の親要素がない場合があるため、`a[href^="/works/{work_id}/episodes/"]` をすべて取得する戦略をとる。

| 項目 | CSSセレクタ / 取得方法 | 備考 |
| :--- | :--- | :--- |
| **エピソードリンク** | `a[href*="/episodes/"]` | 作品ID以下のリンクに限定 |
| **エピソードID** | `href` 属性 | URL末尾の数字列 |
| **サブタイトル** | `[class*="WorkTocSection_title"]` | クラス名部分一致推奨 |
| **公開日** | `time` 要素の `dateTime` 属性 | ISO8601形式で取得可能 |
| **更新日** | （専用の表示がない場合が多い） | 公開日を利用 |
| **次話**  | `a#contentMain-readNextEpisode` | なければ最終話 |

**実装ヒント:**
`WorkTocSection_link__...` のようなクラスを持つ `a` タグを探すか、`href` がエピソード形式（`/episodes/\d+`）のものを抽出する。
内部のタイトルは `class*="WorkTocSection_title"` を持つ `div` 内のテキストを取得する。

## 4. エピソード閲覧ページ（本文）

**対象URL:** `https://kakuyomu.jp/works/{work_id}/episodes/{episode_id}`

### 本文抽出

| 項目 | CSSセレクタ | 備考 |
| :--- | :--- | :--- |
| **エピソードタイトル**| `.widget-episodeTitle` | |
| **本文コンテナ** | `.widget-episodeBody` | |
| **段落テキスト** | `.widget-episodeBody > p` | id属性(`p1`, `p2`...)付き |
| **空行** | `p.blank` | 改行用（`<br>`を含む） |

### ページネーション（次の話）

| 項目 | CSSセレクタ | 備考 |
| :--- | :--- | :--- |
| **次の話へ** | `a#contentMain-readNextEpisode` | `href`属性を取得 |
| **次のタイトル** | `a#contentMain-readNextEpisode .contentMain-pagerEpisodeTitle` | 先読み表示用 |
| **前の話へ** | `a#contentMain-readPreviousEpisode` | (必要なら取得) |

### その他

*   **画像:** 本文中に画像が含まれる場合、`img`タグを別途処理する必要がある（現状の要件ではテキスト主体だが考慮しておく）。
*   **ルビ:** `<ruby>` タグが使用されている。Jsoupの `text()` メソッドはルビを本文と一緒に抽出してしまう可能性があるため、必要に応じて `<rt>` タグを除去するか、ルビ記法（`｜漢字《かんじ》`）に変換する処理を入れる。
<br>
**例:** `<ruby>漢字<rt>かんじ</rt></ruby>` -> `｜漢字《かんじ》`

## 5. エラーハンドリング・例外

*   **ログイン限定:** 一部の作品やエピソードはログインしていないと閲覧できない場合がある。その場合、ログインページへのリダイレクトや特定のメッセージが表示される。
    *   検知方法: タイトルが取得できない、または `form.login-form` 等が存在する場合。
*   **削除済み:** 404エラーが返る。
*   **構造変更:** セレクタで見つからない場合は、`ParseException` を投げ、アプリ側でWebViewフォールバックを行う。
