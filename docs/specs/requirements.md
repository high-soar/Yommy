# 全体要件定義・機能一覧・ロードマップ（App 全体正本）

## 1. プロジェクト概要・目的

**Yommy** は、複数の Web 小説サイト（カクヨム、小説家になろう等）の作品を取得して端末内のローカル DB（SQLite）にキャッシュし、オフライン環境でも縦書き・ルビ・傍点・カラーテーマ等の小説特化組版で快適に読書できる Android 向け Web 小説リーダーアプリケーションです。

### 1.1 ターゲット環境・技術方針

- **対象プラットフォーム**: Android（Capacitor によるハイブリッドネイティブアプリ）および開発・テスト用 Web ブラウザ環境
- **フレームワーク・言語**: React + TypeScript + Vite + Tailwind CSS + Capacitor（`@capacitor/core`, `@capacitor-community/sqlite`）
- **オフラインファースト**: 取得済みの目次・本文データはすべて端末内 SQLite に保存し、圏外・機内モードでも閲覧・しおり保存が可能であること。

## 3. システム機能要件一覧（`SYS-REQ-xx`）

### 3.1 スクレイピング・ローカルキャッシュ・キュー管理

|    要件 ID     | カテゴリ                     | 要件概要                                                                                                                                                                                                |     優先度     |
| :------------: | :--------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------------: |
| **SYS-REQ-01** | 作品登録・目次取得           | 小説の作品トップ URL（またはエピソード URL）を入力し、タイトル・著者・あらすじ・全エピソード目次を取得してローカル DB に登録できる。                                                                    |     `v0.1`     |
| **SYS-REQ-02** | 本文取得・オフライン閲覧     | 指定したエピソード（単話・選択範囲・未取得全話）の本文 HTML を取得してローカル DB に保存し、オフライン環境で閲覧できる。                                                                                |     `v0.1`     |
| **SYS-REQ-03** | レートリミット・DLキュー制御 | 複数話の一括取得時は対象サーバーへの負荷や 503 IP BAN を防ぐため、リクエスト間隔のウェイト制御（例: 1.5秒間隔）を伴うバックグラウンドキューで順次取得し、一時停止・再開・キャンセル・リトライができる。 |     `v0.2`     |
| **SYS-REQ-04** | 更新チェック（差分取得）     | 登録済み作品（お気に入り等）の目次を再取得し、新規追加されたエピソードや改稿されたエピソードを検知して差分ダウンロードできる。                                                                          |     `v0.2`     |
| **SYS-REQ-05** | キャッシュ管理・容量整理     | 作品ごと・アプリ全体のキャッシュデータ容量（Byte/MB）を確認でき、既読エピソードの本文キャッシュ削除・作品単位のキャッシュクリア・作品削除が行える。                                                     | `v0.2`〜`v0.3` |
| **SYS-REQ-06** | バックアップ・復元           | 本棚の登録作品・しおり・既読状態・設定データを JSON 等の形式でエクスポート／インポートできる。                                                                                                          |     `v0.3`     |

### 3.2 小説特化リーダー・組版・操作体験

|    要件 ID     | カテゴリ                       | 要件概要                                                                                                                                                                              |              優先度              |
| :------------: | :----------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------------------------------: |
| **SYS-REQ-07** | ルビ・傍点の正確な描画         | 本文中の `<ruby>`（`<rb>`, `<rt>`, `<rp>`）および傍点表現を、サニタイズ（XSS 防止）しつつ組版崩れなくレンダリングする。                                                               |              `v0.1`              |
| **SYS-REQ-08** | 縦書き / 横書き切り替え        | CSS `writing-mode: vertical-rl`（縦書き）と `horizontal-tb`（横書き）をシームレスに切り替えられる。                                                                                   |              `v0.1`              |
| **SYS-REQ-09** | フォント・サイズ・余白設定     | フォント種別（明朝体 / ゴシック体 / UDフォント / 教科書体等）、文字サイズ、行間、画面余白をカスタマイズし永続化できる。                                                               |          `v0.1`〜`v0.2`          |
| **SYS-REQ-10** | カラーテーマ切り替え           | 白背景（Light）、セピア（Sepia）、ダーク（Dark）、有機EL向け純黒（AMOLED Black）の4テーマを切り替えられる。                                                                           |              `v0.1`              |
| **SYS-REQ-11** | スクロール ＆ 1画面送り操作    | 連続スクロール（縦書き時は右→左の横スクロール、横書き時は上→下の縦スクロール）に加え、画面左右タップや音量キー操作による1画面分のジャンプ送り、および前話・次話への連続遷移ができる。 | `v0.1`（基本）<br>`v0.2`（拡張） |
| **SYS-REQ-12** | しおり・スクロール位置自動保存 | 作品ごとに「現在読んでいるエピソード」と「本文内のスクロール進捗率（0.0〜1.0）」を自動保存し、再開時に同じ位置から読書を再開できる。また既読フラグを自動更新する。                    |              `v0.1`              |

### 3.3 ブラウザ連携（WebView フォールバック）

|    要件 ID     | カテゴリ                      | 要件概要                                                                                                                                 | 優先度 |
| :------------: | :---------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- | :----: |

## 4. ミニリリース Milestone ロードマップ

Phase 3（PoC）で最小骨格を実証した後、Phase 4 以降は 3〜5 個の要望 Issue を束ねた以下のミニリリース Milestone 単位で段階的に機能を完成させます。

```mermaid
flowchart LR
    PoC["<b>Phase 3: PoC (Walking Skeleton)</b><br>・カクヨム1話の取得〜SQLite保存<br>・縦書き/ルビ表示とVRT実証"]
    M1["<b>Milestone v0.1 (MVP)</b><br>・カクヨム作品登録・目次・本文閲覧<br>・本棚/作品詳細/リーダー3画面基本完成<br>・縦横切替・テーマ・しおり保存"]
    M2["<b>Milestone v0.2 (Multi-site & Queue)</b><br>・小説家になろう対応<br>・レートリミット付きDLキュー・一括取得<br>・新着更新チェック・タップ/音量キー送り"]
    M3["<b>Milestone v0.3 (WebView & Storage)</b><br>・内蔵WebView表示＆DOMインポート<br>・キャッシュ容量管理・既読キャッシュ削除<br>・データバックアップ/復元"]

    PoC --> M1 --> M2 --> M3
```
