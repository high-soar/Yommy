## SC-003-001 ランキング・検索画面

### 概要
カクヨム等の外部サイトから小説を検索し、本棚に追加するための画面。ランキング表示とキーワード検索が可能。

### 画面レイアウト

#### ヘッダー（TopAppBar）
- **左側**: 戻るボタン（SC-001-001へ戻る）
- **中央**: タイトル表示「作品を探す」
- **右側**: 検索アイコンボタン（タップで検索バーが展開）

#### 検索バー（展開式）
- 検索アイコンボタンタップ時に、ヘッダー全体が検索バーに切り替わる
  - **左側**: 戻るボタン（検索バーを閉じる）
  - **中央**: テキスト入力フィールド
    - プレースホルダー: 「小説を検索...」
    - クリアボタン（×）
  - **右側**: 検索実行ボタン（虫眼鏡アイコン）
- 検索実行時:
  - タブが自動的に「検索結果」に切り替わる
  - 検索バーは展開されたまま（キーワード編集可能）
  - 検索中はローディングインジケーター（プログレスバー）を表示

#### タブ
- **タブ1**: ランキング（デフォルト選択）
  - ジャンル選択UI: ドロップダウンメニュー（タブ内、作品リストの上部に配置）
    - デフォルト: 「総合ランキング」
    - カクヨムのジャンル（固定リスト）: 総合、恋愛、ファンタジー、文芸、SF、ミステリー、ホラー、その他
    - 選択内容は保持され、次回起動時も前回選択したジャンルを表示
    - ジャンル切り替え時は再スクレイピングを実行（ローディング表示）
- **タブ2**: 検索結果
  - 検索実行後のみ内容が表示される
  - 初期状態（未検索時）: 「キーワードを入力して検索してください」メッセージを表示
  - 検索結果0件時: 「検索結果が見つかりませんでした」メッセージを表示

#### コンテンツエリア（リスト）
- **ローディング状態**:
  - スクレイピング実行中は中央にCircularProgressIndicatorを表示
  - リスト内容はグレーアウトまたは非表示
  - ユーザー操作は可能（タブ切り替え等）だが、新規リクエストは前回リクエスト完了後に実行される

- **作品リストアイテム**:
  - **タイトル**: 全文表示（複数行対応）
  - **作者名**: 1行表示
  - **あらすじ**: 
    - 省略表示: Composeの `maxLines = 3` を使用
    - 省略時には末尾に「...」を付与（`overflow = TextOverflow.Ellipsis`）
    - HTMLタグはすべて除去し、プレーンテキストとして表示
    - タップで作品詳細ダイアログを表示（全文あらすじ、公式サイトへのリンクボタン）
  - **付帯情報**: 
    - ジャンル（例: 「ファンタジー」）
    - 総話数（例: 「全123話」）
    - 最終更新日（例: 「2026/02/15更新」）
    - これらはスクレイピング時に取得し、`SearchCache` テーブルまたは `Novels` テーブル（登録済みの場合）から取得
  - **追加ボタン**:
    - **未登録時**: 
      - 「＋」アイコンボタン（アクセントカラー）
      - タップ時、即座に「登録済」状態に切り替わる（楽観的UI更新）
      - バックグラウンドで非同期にDBへ保存
      - 保存失敗時はSnackbarでエラー表示し、ボタンを「未登録」に戻す
    - **登録済み**: 
      - チェックマークアイコン（グレー、非活性）
      - 判定ロジック:
        - リスト取得時に各作品IDで `Novels` テーブルを検索
        - `Novels.id` と `site_source` の組み合わせで判定（異なるサイト間は別作品として扱う）
        - StateFlowで登録状態を監視し、リアルタイムに反映

### イベント・アクション

| トリガー | アクション | 遷移先/振る舞い |
| :--- | :--- | :--- |
| 検索アイコンタップ | ヘッダーが検索バーに展開 | - |
| キーワード入力 → 検索実行 | 1. 検索APIスクレイピング実行（3秒インターバルは単一リクエストのため不要）<br>2. キャッシュチェック（1時間以内のキャッシュがあれば使用）<br>3. 検索結果を `SearchCache` テーブルに保存 | 「検索結果」タブに自動切り替え、リスト更新 |
| 追加ボタン押下 | 1. 楽観的UI更新（即座に「登録済」表示）<br>2. 作品情報を `Novels` テーブルにINSERT（UNIQUE制約により重複防止）<br>3. 失敗時はロールバック＋エラー表示 | ボタン状態変更 |
| 作品アイテムタップ | 作品詳細ダイアログを表示（全文あらすじ＋メタ情報） | モーダルダイアログ表示 |
| 詳細ダイアログ内「公式サイトを開く」ボタン | 1. URLホワイトリスト検証（kakuyomu.jpドメインのみ許可）<br>2. 確認ダイアログ表示: 「外部ブラウザで開きますか？」<br>3. 承認後、外部ブラウザで開く | 外部ブラウザ |
| タブ切り替え | 表示コンテンツの切り替え | - |
| ジャンル切り替え（ドロップダウン） | 1. 選択内容を保存（SharedPreferences等）<br>2. キャッシュチェック（1時間以内のキャッシュがあれば使用）<br>3. 期限切れの場合は再スクレイピング実行（ローディング表示） | ランキングリスト更新 |
| パース失敗エラー発生 | エラーダイアログを表示（「Webで開く」ボタン付き） | - |
| エラーダイアログ「Webで開く」ボタン | 外部ブラウザで該当URL(カクヨムの公式ページ)を開く(フォールバック) | 外部ブラウザ |

### エラーハンドリング

#### ネットワークエラー
- **発生タイミング**: スクレイピングリクエスト時にネットワーク未接続、タイムアウト（15秒）
- **UI表示**: リスト中央にエラーメッセージと「再試行」ボタンを表示
  - メッセージ例: 「ネットワークエラーが発生しました」
- **リトライ**: 最大3回まで自動リトライ（指数バックオフ: 1秒、2秒、4秒）
- **リトライ失敗後**: ユーザーによる手動リトライのみ可能

#### 解析エラー
- **発生タイミング**: HTMLパースに失敗（DOM構造変更等）
- **UI表示**: エラーメッセージと「Webで開く」ボタンを表示
  - メッセージ例: 「データの取得に失敗しました。サイト構造が変更されている可能性があります」
- **フォールバック**: 「Webで開く」ボタン押下で、外部ブラウザで該当URL(カクヨムの公式ページ)を開く

#### DB保存エラー
- **発生タイミング**: `Novels` テーブルへのINSERT失敗（UNIQUE制約違反以外）
- **UI表示**: Snackbarで通知し、ボタン状態を「未登録」に戻す
  - メッセージ例: 「登録に失敗しました」

### データフロー

#### ランキング表示
1. タブ選択 or ジャンル切り替え
2. キャッシュ確認（`SearchCache` テーブル、有効期限1時間）
   - キャッシュヒット → キャッシュから取得して表示
   - キャッシュミス → スクレイピング実行
3. スクレイピング結果を `SearchCache` に保存（古いキャッシュは削除）
4. 各作品について `Novels` テーブルで登録状態を確認
5. リスト表示

#### 検索実行
1. キーワード入力 → 検索実行
2. キャッシュ確認（`cache_key = "search:{keyword}"`）
   - キャッシュヒット → キャッシュから取得
   - キャッシュミス → スクレイピング実行
3. 以降はランキング表示と同様

#### 作品登録
1. 追加ボタン押下
2. 楽観的UI更新（即座に「登録済」表示）
3. `Novels` テーブルにINSERT ON CONFLICT IGNORE
   - 成功 → StateFlow更新により他のアイテムも自動更新
   - 失敗 → UIロールバック＋エラー表示

### 画面遷移
- **戻るボタン**: SC-001-001（本棚画面）へ遷移
- **作品詳細ダイアログ**: モーダル表示（画面遷移なし）
- **公式サイトを開く**: 外部ブラウザ起動（アプリ外遷移）

### 備考
- スクレイピング間隔: 単一リクエストのため、要件定義の「3秒インターバル」は適用外
  - ただし、ジャンル連続切り替え等で短時間に複数リクエストが発生する場合は、リクエストキューで管理し、前回リクエスト完了後に次を実行
- オフライン対応: キャッシュ内データは期限切れでもオフライン時には表示可能（「古いデータ」表示）
