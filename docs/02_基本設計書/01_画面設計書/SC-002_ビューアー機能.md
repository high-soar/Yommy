## SC-002-001 ビューアー画面

### 概要
小説の本文を閲覧するための画面。WebViewを使用し、縦スクロールで読み進める。

### 画面レイアウト

この画面は「没入モード」を基本とし、タップ操作で「オーバーレイ（操作パネル）」を表示する。

#### 1. メインコンテンツ（WebView）
- **表示内容**: HTML化された小説本文。
- **スタイル**: SC-002-002で設定されたCSS（フォントサイズ、行間、背景色）を適用。
- **スクロール**: 縦方向のみ。

#### 2. オーバーレイ（ヘッダー）
- **左側**: 戻るボタン（SC-001-001 または SC-001-002 へ戻る）
- **中央**: エピソードタイトル（省略表示）
- **右側**:
  - **目次ボタン**: SC-001-002（目次）へ遷移、またはモーダルで簡易目次表示。
  - **設定ボタン**: SC-002-002（表示設定）を表示。

#### 3. オーバーレイ（フッター）
- **上部**: シークバー（現在のスクロール位置 / ページ全体の位置を表示。この機能は縦スクロールWeb小説では実装難易度が高いため、まずは「進捗％表示」のみとする可能性がある）。
- **下部**:
  - **前の話へ**: 1つ前のエピソードへ遷移。先頭話の場合は非活性。
  - **次の話へ**: 1つ後のエピソードへ遷移。最新話の場合は非活性。

#### 4. コンテンツ末尾（WebView内、またはオーバーレイの一部）
- **「次の話へ」ボタン**: 本文の最後に到達した際に大きく表示し、続けて読むアクションを促す。

### イベント・アクション

| トリガー | アクション | 遷移先/振る舞い |
| :--- | :--- | :--- |
| 画面中央タップ | オーバーレイの表示/非表示切り替え | - |
| 音量ボタン押下 | スクロールダウン/アップ | - |
| 「次の話へ」ボタン押下 | 次のエピソードをロードして表示 | SC-002-001（リロード） |
| 「前の話へ」ボタン押下 | 前のエピソードをロードして表示 | SC-002-001（リロード） |
| 設定ボタン押下 | 表示設定ダイアログを表示 | SC-002-002 |
| バックキー/戻るボタン | 読書位置を保存して終了 | 元の画面へ |

## SC-002-002 表示設定画面

### 概要
ビューアー画面の文字サイズ、背景色、行間などの表示設定を行うための画面（またはダイアログ/ボトムシート）。ビューアー画面の上層に表示される。

### 画面レイアウト

#### 表示形式
- **モーダルボトムシート**: 画面下部からスライドアップして表示。元の本文を見ながら調整可能にする。

#### 設定項目
1.  **カラーテーマ（背景色/文字色）**
    - 選択肢（ラジオボタンまたはアイコン選択）:
      - ホワイト（白背景/黒文字）
      - セピア（薄茶背景/茶文字）
      - ダーク（黒背景/白文字）

2.  **文字サイズ**
    - UI: スライダー（小 <-> 大）または「＋」「ー」ボタン。
    - プレビュー: 設定変更即時に背面のWebViewに反映。

3.  **行間**
    - 選択肢: 狭い / 普通 / 広い

4.  **フォント（将来対応）**
    - 明朝体 / ゴシック体

#### アクションエリア
- **閉じるボタン**: 右上「×」またはシート外タップで閉じる。設定は即時保存される。

### イベント・アクション

| トリガー | アクション | 遷移先/振る舞い |
| :--- | :--- | :--- |
| テーマ選択 | CSSを変更しWebViewに適用、設定保存 | 即時反映 |
| 文字サイズ変更 | CSSを変更しWebViewに適用、設定保存 | 即時反映 |
| シート外タップ | 設定画面を閉じる | SC-002-001へ戻る |
