## 1. 概要
ビューアー画面の見た目（文字サイズ、配色、行間など）をユーザーの好みに合わせてカスタマイズする機能。設定は即時反映され、アプリ全体（またはビューアー全体）で共有・永続化される。

> [!NOTE] 主要機能
> - **文字サイズ変更**: 段階的またはスライダーによる調整。
> - **配色テーマ変更**: ライト、ダーク、セピアなどのプリセット選択。
> - **行間調整**: 読みやすさに応じた行間の変更。
> - **設定の永続化**: 次回起動時も設定を維持する (DataStore)。

## 3. UI状態 (UI State)

### 定義 (`ViewerSettingsUiState`)

```kotlin
data class ViewerSettingsUiState(
    val textSizePercent: Int = 100,      // デフォルト 100%
    val theme: ViewerTheme = ViewerTheme.SYSTEM,
    val lineHeightPercent: Int = 150,    // デフォルト 150% (LineHeight.NORMAL)
    val fontFamily: FontFamily = FontFamily.DEFAULT
)

enum class ViewerTheme(
    val backgroundColor: Int,
    val textColor: Int
) {
    SYSTEM(0, 0), // UI層でLIGHT/DARKに解決する
    LIGHT(0xFFFFFFFF.toInt(), 0xFF000000.toInt()),  // 白背景・黒文字
    DARK(0xFF121212.toInt(), 0xFFE0E0E0.toInt()),   // 黒背景・白文字 (#121212, #E0E0E0)
    SEPIA(0xFFF4ECD8.toInt(), 0xFF5B4636.toInt());  // 薄茶背景・茶文字 (#F4ECD8, #5B4636)
}

object LineHeight {
    const val NARROW = 120
    const val NORMAL = 150
    const val WIDE = 180
}
```

## 4. イベント・関数詳細

### 4.1. ViewModel: `ViewerSettingsViewModel`

| 関数名 | 引数 | 戻り値 | 処理概要 |
| :--- | :--- | :--- | :--- |
| `updateTextSize` | `percent: Int` | `Unit` | 文字サイズパーセンテージを更新・保存する。 |
| `updateTheme` | `theme: ViewerTheme` | `Unit` | 配色テーマを更新・保存する。 |
| `updateLineHeight` | `percent: Int` | `Unit` | 行間を更新・保存する (`LineHeight` 定数を使用)。 |
| `updateFontFamily` | `font: FontFamily` | `Unit` | フォントを更新・保存する。 |

#### 詳細ロジック

**`updateTextSize(percent)`**
1. `userPreferencesRepository.saveTextSize(percent)` を呼び出す（suspend関数）。
2. Repository内部でDataStoreに書き込みを行う。
3. DataStoreはFlowを公開しているため、`ViewerViewModel` 側で監視しているFlowが自動的に更新され、ビューアー画面に即時反映される。

**`updateTheme(theme)`**
1. 同様に `repository.saveTheme(theme)` を呼び出す。
2. `ViewerViewModel` 側でこの値を監視し、WebViewのCSS再生成（`HtmlComposer`）をトリガーする。
    - `SYSTEM` 選択時は、Composeの `isSystemInDarkTheme()` を基に `LIGHT` または `DARK` のカラーコードを解決して `ViewerSettings` に渡す。

## 5. データベース・API アクセス

### DataStore (Proto DataStore or Preferences DataStore)

本アプリでは軽量な設定のため **Preferences DataStore** を使用する。

| Key | 型 | 説明 |
| Key | 型 | 説明 |
| :--- | :--- | :--- |
| `viewer_text_size_percent` | Int | 文字サイズ (ex. 100, 120, etc.) |
| `viewer_theme_mode` | String | テーマEnum名 (SYSTEM, LIGHT, DARK, SEPIA) |
| `viewer_line_height` | Int | 行間パーセント (ex. 150) |
| `viewer_font_family` | String | フォントファミリー名 ("serif", "sans-serif" 等) |

## 6. エラーハンドリング・境界値

| ケース | 挙動 |
| :--- | :--- |
| **極端な値の指定** | UI側で制限（スライダーの最小・最大値）およびRepository側でのバリデーション（範囲外ならクリップする）。 |
| **保存失敗** | IO例外の可能性は低いが、失敗時は再試行または無視（クリティカルではないため）。 |

## 7. 補足 (インタラクション)

- **リアルタイム反映**: 設定シートが表示されている間、背面のWebView（ビューアー）は設定変更に応じて即座に再レンダリング（またはCSS適用）を行う。
- **シートを閉じる**: シート外タップまたは閉じるボタンでシートを非表示にする。

### デフォルト値の定義
- **SYSTEM**: 端末の「ダークテーマ」設定を検知し、LIGHTかDARKを自動判定するロジックが必要（`isSystemInDarkTheme()` Compose関数などで判定）。
