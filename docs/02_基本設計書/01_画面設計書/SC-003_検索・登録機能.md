## SC-003-001 ランキング・検索画面

### 概要
カクヨム等の外部サイトから小説を検索し、本棚に追加するための画面。ランキング表示とキーワード検索が可能。

### 画面レイアウト

#### ヘッダー（TopAppBar）
- **左側**: 戻るボタン（SC-001-001へ戻る）
- **中央**: 検索バー（キーワード入力フォーム）
  - プレースホルダー: 「小説を検索...」
  - 検索アイコンボタン

#### タブ
- **タブ1**: ランキング（デフォルト選択）
  - 総合ランキング / ジャンル別ランキング（ドロップダウン等で切り替え）
- **タブ2**: 検索結果
  - キーワード検索結果を表示

#### コンテンツエリア（リスト）
- **作品リストアイテム**:
  - **タイトル**: 全文表示。
  - **作者名**: 1行表示。
  - **あらすじ**: 省略表示（最大3行）。
  - **付帯情報**: ジャンル、総話数、最終更新日。
  - **追加ボタン**:
    - 未登録時: 「＋」または「追加」ボタン（アクセントカラー）。
    - 登録済み: 「登録切」またはチェックマーク（グレーアウト/非活性）。

### イベント・アクション

| トリガー | アクション | 遷移先/振る舞い |
| :--- | :--- | :--- |
| キーワード入力 -> 検索実行 | 検索API/スクレイピング実行 | 結果リストを更新 |
| 追加ボタン押下 | 作品情報をDBに保存（非同期） | ボタン状態を「登録済」に変更 |
| 作品アイテムタップ | （オプション）ブラウザで公式サイトを開く | 外部ブラウザ |
| タブ切り替え | 表示コンテンツの切り替え | - |
