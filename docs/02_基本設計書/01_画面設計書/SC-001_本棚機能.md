## SC-001-001 本棚一覧画面

### 概要
ユーザーが登録した小説を一覧表示し、読書を開始するためのメイン画面。アプリ起動直後に表示される。

### 画面レイアウト

#### ヘッダー（TopAppBar）
- **左側**: アプリタイトル（Yommy）
- **右側**:
  - **検索・追加ボタン**: [アイコン: 虫眼鏡/プラス] -> SC-003-001へ遷移
  - **メニューボタン**: [アイコン: 三点リーダー] -> ドロップダウンメニュー表示
    - 設定（SC-004-001へ遷移）
    - ライセンス情報
    - バージョン情報

#### コンテンツエリア
- **リスト/グリッド表示**: 登録作品をカード形式で一覧表示（設定で切り替え可能、または固定）。
- **個々の作品カード**:
  - **タイトル**: 2行まで表示、以降省略。
  - **作者名**: 1行表示。
  - **サイトアイコン**: カクヨム/なろう等の識別アイコン。
  - **更新バッジ**: 新着エピソードがある場合に「NEW」や「未読あり」を表示。
  - **未読数**: （オプション）未読エピソード数をバッジ表示。
  - **最終読書日時**: 並び替えに使用。

#### エンプティステート（作品未登録時）
- 画面中央にメッセージ表示：「作品がありません。右上の＋ボタンから作品を追加してください。」

### イベント・アクション

| トリガー | アクション | 遷移先/振る舞い |
| :--- | :--- | :--- |
| 作品カードタップ | 該当作品の目次画面を開く | SC-001-002 |
| 作品カード長押し | コンテキストメニュー表示 | ダイアログ（削除、詳細確認） |
| 検索・追加ボタン押下 | 検索画面を開く | SC-003-001 |
| メニュー：設定選択 | 設定画面を開く | SC-004-001 |
| リストのプルダウン | 全作品の更新チェック実行（UC2） | バックグラウンドで実行し、画面上部に進捗インジケーター（プログレスバー）を表示。操作はブロックしない。 |

## SC-001-002 作品目次画面

### 概要
選択した小説のエピソード一覧（目次）を表示し、読みたい話を選択する画面。作品の詳細情報も確認できる。

### 画面レイアウト

#### ヘッダー（TopAppBar）
- **左側**: 戻るボタン（SC-001-001へ戻る）
- **中央**: 作品タイトル（スクロールでフェードイン、または常時表示）
- **右側**:
  - **更新ボタン**: [アイコン: 更新] -> 手動更新チェック
  - **URLコピー**: 「クリップボードにコピーしました」トースト表示。
  - **ブラウザで開く**: 外部ブラウザで作品トップページを開く。
  - **メニュー**:
    - 削除

#### コンテンツエリア（スクロール）

##### 1. 作品情報ヘッダー
- **タイトル**: 全文表示。
- **作者名**: クリックで作者検索（将来対応）。
- **あらすじ**: デフォルトは先頭3行程度表示、タップで展開/折りたたみ。
- **タグ**: `tags`カラムに保存されたタグをチップ表示（スクロール可）。
- **ステータス**: 解析エラー時は「解析失敗」と表示し、「Webで開く」ボタンを表示する（フォールバック）。
- **アクションボタン**: 「続きから読む」（最後に読んだ話・位置へ遷移）。

##### 2. 目次リスト
- **セクション見出し**: 章などが設定されている場合は区切りとして表示。
- **エピソード行**:
  - **サブタイトル**: 話のタイトル。
  - **投稿日時/更新日時**: 日付を表示。
  - **既読状態**: `is_read`フラグがtrueの場合は文字色を薄くする。
  - **未読バッジ**: 未読の場合、目立つ色で表示。
  - **キャッシュ状態**: 保存済み（オフライン可）かどうかのインジケーター（アイコン）。

### イベント・アクション

| トリガー | アクション | 遷移先/振る舞い |
| :--- | :--- | :--- |
| 戻るボタン押下 | 本棚へ戻る | SC-001-001 |
| 「続きから読む」押下 | 最後に読んだ話・位置を開く | SC-002-001 |
| エピソード行タップ | 該当エピソードを開く | SC-002-001 |
| 更新ボタン押下 | 目次情報の再取得・更新 | （通信処理＋リスト更新） |
| メニュー：削除 | 確認ダイアログ表示 -> 削除実行 | SC-001-001（削除後戻る） |
