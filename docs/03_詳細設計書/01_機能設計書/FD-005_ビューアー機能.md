## 1. 概要

小説の本文を表示し、ユーザーに快適な読書体験を提供する。
WebViewを使用し、縦スクロール形式で閲覧可能にする。また、スムーズな読書体験のために先読みキャッシュや、中断位置からの再開（レジューム）機能を実装する。

> [!NOTE] 主要機能
> - **HTML表示**: 取得したHTMLコンテンツを整形し、カスタムCSSを適用して表示する。
> - **ページネーション**: ストーリーの順序に従って「前の話」「次の話」へ遷移する。
> - **レジューム**: 読書位置（スクロール位置や段落）を保存し、次回起動時に復帰する。
> - **先読みキャッシュ**: 読書中に次のエピソードをバックグラウンドで取得する。
> - **操作系**: 音量キーによるスクロール、タップによるメニュー表示。

## 3. UI状態 (UI State)

### 定義 (`ViewerUiState`)

```kotlin
data class ViewerUiState(
    val isLoading: Boolean = true,
    val novelTitle: String = "",
    val currentEpisode: Episode? = null,
    val nextEpisodeId: Long? = null,
    val prevEpisodeId: Long? = null,
    val viewerSettings: ViewerSettings = ViewerSettings(),
    val errorMessage: String? = null,
    val isMenuVisible: Boolean = false, // オーバーレイ表示状態
    val readingProgress: Float = 0f // 読書進捗 (0.0 - 1.0)
)

data class ViewerSettings(
    val textSizePercent: Int = 100,
    val backgroundColor: Int = 0xFFFFFFFF.toInt(),
    val textColor: Int = 0xFF000000.toInt(),
    val lineHeightPercent: Int = 150,
    val fontFamily: String = "serif"
) {
    // HTML用カラーコード変換
    val backgroundColorHex: String get() = String.format("#%06X", 0xFFFFFF and backgroundColor)
    val textColorHex: String get() = String.format("#%06X", 0xFFFFFF and textColor)
}
```

> - **currentEpisode**: 表示中のエピソードデータ。`content_html` がnullの場合は取得処理が走る。
> - **nextEpisodeId / prevEpisodeId**: 前後のエピソードID。遷移ボタンの活性/非活性制御に使用。
> - **viewerSettings**: `UserPreferencesRepository` から流れてくる設定値。
> - **readingProgress**: プログレスバー表示用。

## 4. イベント・関数詳細

### 4.1. ViewModel: `ViewerViewModel`

| 関数名 | 引数 | 戻り値 | 処理概要 |
| :--- | :--- | :--- | :--- |
| `loadEpisode` | `episodeId: Long` | `Unit` | 指定エピソードを表示する。未取得ならネットワークから取得。 |
| `onScrollChange` | `scrollY: Int, contentHeight: Int` | `Unit` | スクロール位置の通知を受ける（JSInterface経由）。 |
| `onProgressChange` | `progress: Float` | `Unit` | 読書進捗の更新を受け取る。 |
| `saveReadingPosition` | `paragraphIndex: Int` | `Unit` | 現在の段落位置を永続化する。 |
| `moveToNext` | なし | `Unit` | 次のエピソードへ遷移。 |
| `toggleMenu` | なし | `Unit` | メニュー表示/非表示の切り替え。 |

#### 詳細ロジック

**`loadEpisode(episodeId)`**
1. `_uiState.update { it.copy(isLoading = true) }`
2. `novelRepository.getEpisode(episodeId)` を取得。
3. エピソードデータの確認:
    - レコードが存在し、かつ `content_html` が空の場合:
        - `novelRepository.fetchEpisodeBody(episode.url)` を実行（DB内のURLを使用）。
    - レコード自体が存在しない場合:
        - 基本的にこのルートはあり得ない（目次取得済み前提）が、万一の場合はエラー表示。
    - 取得失敗時は `errorMessage` をセット。
4. 前後のエピソードIDを特定するため、`novelRepository.getNeighborEpisodeIds(episodeId)` を呼ぶ。
5. `_uiState` を更新し、`HtmlComposer` で生成したHTMLをWebViewにロード。
    - **重要**: ロード完了時に、前回保存された `last_read_position` (段落ID等) へジャンプするJSを実行。
6. **先読み処理**: `WorkManager` またはコルーチンで `prefetchNextEpisodes(currentEpisode.index_order)` を非同期実行。

**`saveReadingPosition(paragraphIndex)`**
1. 画面終了時 (`onDispose`) やページ遷移時に呼び出す。
2. `novelRepository.updateLastRead(novelId, episodeId, paragraphIndex)` を実行。

### 4.2. ViewHelper: `HtmlComposer`

WebViewに流し込むHTMLを作成する。

```kotlin
fun composeHtml(body: String, settings: ViewerSettings): String {
    // CSS生成ロジック（実際には別ファイルや定数で管理推奨）
    val css = """
        body {
            font-size: ${settings.textSizePercent}%;
            line-height: ${settings.lineHeightPercent}%;
            background-color: ${settings.backgroundColorHex};
            color: ${settings.textColorHex};
            font-family: ${settings.fontFamily};
            padding: 16px;
        }
        ruby rt { font-size: 50%; }
        /* その他カスタムCSS */
    """.trimIndent()

    return """
        <!DOCTYPE html>
        <html>
        <head>
            <meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">
            <style>
                $css
            </style>
        </head>
        <body>
            <div id="content">$body</div>
            <script>
                // 段落特定ロジック
                // IntersectionObserver を使用して、現在のビューポート上端に最も近い要素を特定する
                const observer = new IntersectionObserver((entries) => {
                    entries.forEach(entry => {
                        if (entry.isIntersecting) {
                            // Android側に現在の段落インデックスを通知
                            // id="p_123" などの形式を想定してパース
                            const pId = entry.target.id;
                            Android.onParagraphChange(pId);
                        }
                    });
                }, { rootMargin: '-10% 0px -90% 0px' }); // 上部10%のエリアで判定

                document.querySelectorAll('p').forEach(p => observer.observe(p));

                // 読書進捗通知
                window.onscroll = () => {
                   const total = document.body.scrollHeight - window.innerHeight;
                   const progress = window.scrollY / total;
                   Android.onProgressChange(progress);
                };
            </script>
        </body>
        </html>
    """.trimIndent()
}
```

## 5. データベース・API アクセス

### データベース (Room DAO)
- `EpisodeDao.getEpisode(id)`: 指定エピソードの取得。
- `EpisodeDao.getNeighborIds(novelId, indexOrder)`: 前後のエピソードID取得。
- `NovelDao.updateReadingProgress(novelId, episodeId, position)`: 読書履歴の更新。

### API
- 本文未取得時に `KakuyomuApiService` を経由してスクレイピング実行。
- 3秒間隔のアクセス制限（FD-003参照）を遵守する。

## 6. エラーハンドリング・境界値

| ケース | 挙動 | ユーザーへのフィードバック |
| :--- | :--- | :--- |
| **本文パース失敗** | エラー画面表示。「ブラウザで開く」オプションを提供。 | 「本文の解析に失敗しました」ダイアログ。 |
| **オフライン & キャッシュなし** | 通信エラー表示。 | スナックバーで「オフラインのため読み込めません」と表示。 |
| **最終話で「次へ」** | ボタンを非表示または無効化。 | - |

## 7. 補足 (WebView連携)

### JavascriptInterface
WebViewとネイティブ側の連携に使用。
- `onTapCenter()`: メニューの表示切替。
- `onScroll(scrollY, totalHeight)`: スクロール位置の通知。
- `onReachBottom()`: コンテンツ末尾到達時の通知（「次の話へ」オーバーレイ表示トリガー）。

### キーイベント
- `KeyEvent.KEYCODE_VOLUME_UP/DOWN`: WebViewのスクロールメソッド (`pageUp/pageDown` or `scrollBy`) を呼び出す。
