## 1. 概要
アプリで使用しているオープンソースソフトウェア（OSS）のライセンス情報を一覧表示する画面。

---

## 2. クラス・ファイル構成

| 分類 | クラス名/ファイル名 | 役割・責務 |
| :--- | :--- | :--- |
| **View (Compose)** | `LicenseScreen.kt` | ライセンスリストの表示。 |
| **Data** | `LicenseItem.kt` | ライセンス情報のデータモデル。 |
| **Asset** | `assets/licenses.json` | ライセンス定義データ（静的ファイル）。 |
| **Utils** | `LicenseLoader.kt` | JSONファイルの読み込みとパースを行うヘルパー。 |

---

## 3. UI状態 (UI State)

### 定義 (`LicenseUiState` - 必要であれば)

単純な静的リスト表示のため、ViewModelを経由せず、Composeの `remember` や `produceState` でロードしても良いが、一貫性のためViewModelを使用してもよい。今回は軽量実装としてViewModelなし、または簡易的なLoaderを使用する想定。

```kotlin
data class LicenseItem(
    val libraryName: String,
    val licenseName: String,
    val licenseText: String, // 全文
    val url: String? = null
)
```

---

## 4. データソース詳細

### `assets/licenses.json` 構成案

保守性とデータサイズ削減のため、ライセンス本文とライブラリ定義を分離する。

```json
{
  "licenses": {
    "Apache-2.0": "Licensed under the Apache License, Version 2.0...",
    "MIT": "Permission is hereby granted, free of charge..."
  },
  "libraries": [
    {
      "name": "Retrofit",
      "licenseId": "Apache-2.0",
      "url": "https://square.github.io/retrofit/"
    },
    {
      "name": "OkHttp",
      "licenseId": "Apache-2.0",
      "url": "https://square.github.io/okhttp/"
    }
  ]
}
```

> [!NOTE] 将来的な移行
> アプリ規模が大きくなった場合、手動管理の限界を超えるため `com.google.android.gms.oss-licenses-plugin` の導入を推奨する。現状は依存関係を最小限にするため独自JSONを採用する。

---

## 5. UI実装詳細

- **Loader**:
  - アプリ起動時または画面遷移時にJSONを非同期読み込み。
  - `libraries` の `licenseId` をキーに `licenses` から本文を結合し、`LicenseItem` リストを生成する。

- **LazyColumn**: ライセンス数が増えてもパフォーマンスを維持するため使用。
- **ExpandableCard**:
  - 各アイテムはクリック可能。
  - Googleの「設定 > デバイス情報 > 法的情報 > オープンソースライセンス」のようなUI、あるいはシンプルなアコーディオンUIを採用。
  - 初期状態は折りたたまれ、タップでライセンス全文を展開表示。

---

## 6. エラーハンドリング

| ケース | 挙動 | ユーザーへのフィードバック |
| :--- | :--- | :--- |
| **JSON読み込み失敗** | **致命的エラー**として扱い、画面にエラーを表示。アプリの主要機能利用をブロックする（コンプライアンス遵守のため）。 | 「ライセンス情報の読み込みに失敗しました。再試行してください。」ボタンを表示。 |
| **パース失敗** | 同上。 | 同上。 |
| **ライセンスID不整合** | 該当アイテムに「Unknown License」と表示（またはビルド時にテストで検知する）。 | - |

> [!CAUTION] 法的リスク
> ライセンス表示ができない状態でアプリを提供することはライセンス違反となる可能性があるため、エラー時は「表示なし」で済ませず、ユーザーに異常を通知して修正（再インストール等）を促すこと。
