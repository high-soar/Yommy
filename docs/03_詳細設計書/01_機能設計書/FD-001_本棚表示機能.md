## 1. 概要
ユーザーが登録した小説を一覧表示し、読書を開始するための起点となる機能。
アプリ起動時のホーム画面として機能し、登録作品の管理（閲覧、更新チェック、削除）へのアクセスを提供する。

> [!NOTE] 主要機能
> - 登録済み小説リストの表示（カード形式/リスト形式）。
> - **未読管理**: 更新がある作品にはバッジを表示。
> - **各種アクションへの導線**: 読書開始、作品詳細、検索画面、設定画面への遷移。

## 3. UI状態 (UI State)

### 定義 (`BookshelfUiState`)

```kotlin
data class BookshelfUiState(
    val isLoading: Boolean = true,
    val novels: List<Novel> = emptyList(),
    val errorMessage: String? = null,
    val isRefreshing: Boolean = false // SwipeToRefresh用
)
```

> - **isLoading**: 初回DB読み込み中のプログレス表示用。
> - **novels**: 表示する作品リスト。ソート順は「最終読書日時（`last_read_at`）」の降順とする。
> - **isRefreshing**: ユーザーによる手動更新（Swipe-to-Refresh）中のインジケータ制御。

## 4. イベント・関数詳細

### 4.1. ViewModel: `BookshelfViewModel`

| 関数名 | 引数 | 戻り値 | 処理概要 |
| :--- | :--- | :--- | :--- |
| `loadNovels` | なし | `Unit` | ローカルDBから全ての登録作品を取得し、`uiState`を更新する。`init`ブロックで呼び出す。 |
| `refreshAll` | なし | `Unit` | 全作品の更新チェック（最新話取得）を行う。バックグラウンド処理完了後、リストを再ロード。 |
| `deleteNovel` | `novelId: String` | `Unit` | 指定された作品および関連エピソードをDBから削除する。 |
| `clearError` | なし | `Unit` | エラーメッセージ（スナックバー）を消去する。 |

#### 詳細ロジック

**`loadNovels()`**
1. `_uiState.update { it.copy(isLoading = true) }`
2. `viewModelScope.launch` で実行。
3. `novelRepository.getAllNovelsFlow()` を購読（collect）。
    - DBの変更をリアルタイムで検知し、自動的にUIを更新するため `Flow` を使用する。
4. 取得データの変換:
    - リストが空の場合でもそのまま `novels` にセット（View側でEmptyStateを表示）。
5. `_uiState.update { it.copy(isLoading = false, novels = list) }`
6. エラー発生時は `errorMessage` にセット。

**`refreshAll()`** (Swipe-to-Refresh)
1. `_uiState.update { it.copy(isRefreshing = true) }`
2. `WorkManager`の`OneTimeWorkRequest`を作成し、`NovelUpdateWorker`（FD-003参照）を実行キューに入れる。
    - **注意**: Repositoryのメソッドを直接呼ぶのではなく、WorkManager経由でバックグラウンド実行することで、大量データ更新時のANRを回避する（FD-003の制約に従う）。
3. 処理完了後、`_uiState.update { it.copy(isRefreshing = false) }`。
4. ※更新結果はDBに書き込まれ、`loadNovels`のFlowが検知して自動反映される。

**`deleteNovel(novelId)`**
1. ユーザー確認ダイアログ（View側制御）で「削除」選択後に呼び出される。
2. `viewModelScope.launch` で実行。
3. `novelRepository.deleteNovel(novelId)` を実行。
    - `Episodes`テーブルの関連データもCascade削除される（DB設計参照）。
4. 成功時、DB Flowにより自動的にリストから消える。
5. 失敗時、`errorMessage` に「削除に失敗しました」をセット。

## 5. データベース・API アクセス

### データベース (Room DAO)

- **`NovelDao.getAllNovelsFlow(): Flow<List<Novel>>`**
  - クエリ: `SELECT * FROM novels ORDER BY last_read_at DESC`
  - 目的: 作品リストの常時監視・表示。
- **`NovelDao.delete(novelId: String)`**
  - 目的: 作品削除。

### API

- 本機能（FD-001）では直接APIを呼び出さない（更新機能 FD-003 に委譲）。

## 6. エラーハンドリング・境界値

| ケース | 挙動 | ユーザーへのフィードバック |
| :--- | :--- | :--- |
| **DB読み込みエラー** | リスト表示不可。 | スナックバーまたは画面中央に「読み込みエラー」と再試行ボタンを表示。 |
| **作品数0件** | Empty Stateを表示。 | 「作品がありません。右上の＋ボタンから追加してください」のメッセージとイラストを表示。 |
| **削除エラー** | 削除処理中断。 | スナックバーで「削除できませんでした」と表示。 |
| **更新中の画面遷移** | 更新処理はバックグラウンドで継続。 | UI上は更新インジケータが消えるが、処理は継続される（WorkManagerの場合）。 |

## 7. 補足
