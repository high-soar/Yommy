## 1. 概要
登録済みの小説をデータベースから削除する機能。
本棚画面での長押し、または作品詳細画面のメニューから実行可能。
関連するエピソードデータ（本文キャッシュ含む）も同時に完全に削除する。

> [!NOTE] 主要機能
> - 削除確認ダイアログの表示。
> - 作品データ（`Novels`）の削除。
> - 関連エピソードデータ（`Episodes`）の削除（Cascade）。
> - 完了後の画面遷移（詳細画面からの削除時は本棚へ戻る）。

## 3. UI状態 (UI State)

削除処理自体は一瞬で完了するため、専用のUI State構造体は不要だが、以下の状態管理が必要。

- **`showDeleteDialog`: Boolean**
    - 確認ダイアログの表示/非表示を制御。
- **`deletingNovel`: Novel?**
    - 削除対象の作品を一時保持（特に本棚一覧での長押し時）。

## 4. イベント・関数詳細

### 4.1. ViewModel

共通ロジックとして `deleteNovel` を実装する。
**注意**: FD-001（本棚）やFD-002（詳細）からも削除機能が呼び出されるが、削除フローの定義はこのFD-004を正とし、各ViewModelはここのロジック等価の実装を行う（または共通のUseCase/Repositoryメソッドを呼び出す）。

| 関数名 | 引数 | 戻り値 | 処理概要 |
| :--- | :--- | :--- | :--- |
| `onDeleteClicked` | `novel: Novel` | `Unit` | ダイアログを表示し、削除対象をセットする。 |
| `confirmDelete` | なし | `Unit` | 実際に削除を実行する。 |
| `cancelDelete` | なし | `Unit` | ダイアログを閉じ、削除対象をクリアする。 |

#### 詳細ロジック (`confirmDelete`)

1. `deletingNovel` がnullでないことを確認。
2. `viewModelScope.launch` で実行。
3. `repository.deleteNovel(deletingNovel.id)` を呼び出し。
4. 成功時:
    - `showDeleteDialog = false`
    - `deletingNovel = null`
    - トーストまたはスナックバーで「削除しました」と表示。
    - （詳細画面の場合）`NavigateUp` イベントを発行して本棚に戻る。
5. 失敗時:
    - ダイアログを閉じる。
    - エラーメッセージを表示。

## 5. データベース・API アクセス

### データベース (Room DAO)

- **`NovelDao.delete(novel: Novel)`** (または `deleteById(id: String)`)
    - 外部キー制約設定:
      ```sql
      FOREIGN KEY(novel_id) REFERENCES Novels(id) ON DELETE CASCADE
      ```
      により、`Episodes` テーブルおよび `NovelTags` テーブル（ある場合）の関連レコードは自動的に削除される。
    - **注意**: `DELETE FROM Novels WHERE id = :id` クエリを使用する場合、Room等の設定によってはCascadeが効かない場合があるため、エンティティ削除(`@Delete`)を推奨、または`ON DELETE CASCADE`が機能するようDB設定を確認すること。

## 6. エラーハンドリング・境界値

| ケース | 挙動 | ユーザーへのフィードバック |
| :--- | :--- | :--- |
| **削除中にアプリ終了** | トランザクションによりRollbackされるか、中途半端に残る可能性は低い（Roomのトランザクション管理に依存）。 | 次回起動時に再試行可能。 |
| **詳細画面で削除実行** | 本棚一覧へ遷移。 | 削除直後なのでデータ取得エラーにならないよう、View側でナビゲーションを先にトリガーする等の配慮が必要。 |

## 7. 補足 (ダイアログ文言)

ユーザーの誤操作を防ぐため、以下のメッセージを表示する。

**タイトル**: 作品を削除しますか？
**本文**:
「[作品タイトル]」を削除します。
ダウンロード済みのエピソードも全て削除されます。この操作は元に戻せません。

**ボタン**:
- キャンセル (TextButton)
- 削除 (TextButton, Color: Red)
