## SC-004-001 アプリ設定画面

### 概要
アプリケーション全体の共通設定を行う画面。

### 画面レイアウト

#### ヘッダー
- **左側**: 戻るボタン
- **中央**: タイトル「設定」

#### 設定リスト（PreferenceScreenライクな表示）

##### 1. データ設定
- **先読み話数**:
  - 設定値: なし / 3話 / 5話 / 10話
  - 概要: 読書中にバックグラウンドで直後の話を事前取得する数。
- **キャッシュ管理**:
  - **キャッシュ削除**: タップで確認ダイアログ表示 -> 全作品の本文データを削除。

##### 2. システム
- **テーマ設定**:
  - システムに従う / ライト / ダーク（アプリ全体のテーマ）
- **初期化**:
  - **全データ削除**: タップで警告ダイアログ -> DBをDROPして再作成（ライブラリも空になる）。

##### 3. 情報
- **バージョン**: アプリバージョン（例: 1.0.0）
- **ライセンス**: オープンソースライセンス一覧画面へ遷移。

### イベント・アクション

| トリガー | アクション | 遷移先/振る舞い |
| :--- | :--- | :--- |
| 先読み話数変更 | Preferenceに保存 | 即時反映 |
| キャッシュ削除タップ | 「本当に削除しますか？」ダイアログ | OKで削除実行 |
| 全データ削除タップ | 「元に戻せません」警告ダイアログ | OKで全データ消去 -> 本棚へ |
