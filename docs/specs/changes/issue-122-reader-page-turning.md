# 差分仕様書：リーダーのページめくり表示（タップ/スワイプ送り）とスクロール表示切替機能（Issue #122）

本ドキュメントは、Issue #122「`[v0.4] リーダーのページめくり表示（タップ/スワイプ送り）とスクロール表示の切替機能の実装`」に対する差分仕様、影響する App 全体正本の一覧、UT/VRT/IT テスト計画、および実装 Sub-issue 分割計画を定義する設計書です。

---

## 1. 変更の背景・目的（Why）

- **現状の課題**:
  - 縦書き（`vertical-rl`）で小説を読む際、現在の連続横スクロールでは画面端で行が縦半分に途切れたり、微調整のための細かなスクロールが必要となり、読書への没入感を損なっていた。
  - 紙の本や専用電子書籍リーダーのように「1ページ単位でスッとめくる感覚」で快適に読めるページ送り機能が求められている。
  - 一方で横書き（`horizontal-tb`）の場合は縦方向の連続スクロールが自然であるため、組み方向に応じた最適な閲覧スタイルを自動選択しつつ、ユーザーの好みに応じて設定画面で切り替えられるようにする必要がある。
  - また、ページめくり時・スクロール時のいずれにおいても、読み終わった流れで下部オーバーレイを開くことなくシームレスに次のエピソードへ読み進められる操作性が求められている。
- **改善目的**:
  - **電子書籍ライクな 1 ページ組版とページめくり体験**:
    - 画面端で行が途切れない 1 ページ単位の組版（マルチカラム／ページ分割）、本をめくるようななめらかな横スライドアニメーション、および画面隅の控えめなページインジケーター（例: `3 / 12`）を提供する。
  - **Kindle 様式の直感的かつ誤操作のないジェスチャー操作**:
    - 指の動きにリアルタイムに水平追従するダイレクトマニピュレーション、規定値（画面幅の 30%）未満での滑らかなスナップバック復帰（キャンセル挙動）、画面左右端タップ送り、および画面中央タップでのオーバーレイ開閉を実現する。
  - **エピソード境界でのシームレス前後話遷移**:
    - ページめくり時は最終ページからのさらなるドラッグに対するラバーバンド（ゴム抵抗感）と指離しによる次話遷移、スクロール時は読み逃しを防ぐ 2 段階操作による次話遷移を提供する。
  - **しおり進捗率の完全連動**:
    - ページめくりモードにおいても現在ページ位置を進捗率（`0.0〜1.0`）として算出して DB 保存し、再訪時に正確なページ位置を復元する。

## 2. 要求仕様と設計合意事項（What）

### 2.1 ページ送りモード設定と永続化（`SYS-REQ-11` / `SCR-05` 拡張）

リーダー設定（`reader_settings` テーブル）にページ送り動作モード（`paging_mode`）を追加し、設定画面（`SCR-05`）の組版設定セクションで切り替え・永続化可能とする。

#### 型定義契約（`src/storage/types.ts`）

```ts
/**
 * ページ送り動作モード
 * - auto: 自動（縦書き時はページめくり、横書き時はスクロール）
 * - paged: 常に 1 画面単位のページめくり
 * - scroll: 常に連続スクロール
 */
export type ReaderPagingMode = "auto" | "paged" | "scroll";

export interface ReaderSettings {
  writingMode: WritingMode;
  theme: ReaderTheme;
  fontFamily: ReaderFontFamily;
  fontSizePx: number;
  lineHeight: number;
  pageMarginPx: number;
  enableTapPaging: boolean;
  enableVolumeKeyPaging: boolean;
  pagingMode: ReaderPagingMode; // 【新設: v0.4 Issue #122】
  updatedAt: string;
}
```

#### 実効モード（`effectivePagingMode`）の算出ルール

リーダー表示時、設定された `pagingMode` と現在の組み方向 `writingMode` から、以下の純粋関数に基づいて実効動作モード（`"paged" | "scroll"`）を算出する。

```ts
export function resolveEffectivePagingMode(
  pagingMode: ReaderPagingMode,
  writingMode: WritingMode,
): "paged" | "scroll" {
  if (pagingMode === "paged") return "paged";
  if (pagingMode === "scroll") return "scroll";
  // "auto": 縦書き時はページめくり、横書き時はスクロール
  return writingMode === "vertical-rl" ? "paged" : "scroll";
}
```

#### 設定画面（`SCR-05`）の UI 統合

設定画面の組版設定セクションに「ページ送り」切り替えセレクター（`data-testid="paging-mode-select"`）を追加する。

- 選択肢:
  - `auto`: 「自動（縦書き: めくり / 横書き: スクロール）」
  - `paged`: 「ページめくり」
  - `scroll`: 「連続スクロール」
- 選択変更時は即座に `settingsRepository.updateReaderSettings({ pagingMode })` を呼び出し永続化する。

### 2.2 1ページ単位の組版・スライドアニメーション・ページ数表示（`SCR-03`）

実効モードが `"paged"` の場合、以下の組版・表示制御を適用する。

1. **画面端で行が途切れない 1 ページ組版**:
   - ビューポートの幅・高さ、文字サイズ（`fontSizePx`）、行間（`lineHeight`）に応じた 1 ページ内に収まる単位で組版を行う（CSS カラム分割 `column-width` / `column-gap` / `column-fill: auto`、またはコンテナ寸法に基づくページ分割）。
   - 縦書き（`vertical-rl`）時、画面幅の端で行が途中で半分切れて描画されることを防ぎ、1 画面内に整数本の行が美しく整列する。
2. **なめらかな横スライドアニメーション**:
   - ページめくり実行時、本をめくるような自然で視認性の高い 2D 横スライドアニメーション（150〜250ms、推奨 `200ms ease-out`）で遷移する。
3. **控えめなページインジケーター**:
   - 画面の隅（縦書き時は読書の邪魔にならない左下または右下隅）に、控えめなフォントサイズ・透過度で現在ページと総ページ数を示すインジケーター（`data-testid="reader-page-indicator"`、例: `3 / 12`）を表示する。
   - オーバーレイ表示状態に関わらず、読書中の目安として常時表示（または操作後フェードアウト）する。

---

### 2.3 Kindle 様式の直感的なページめくり操作（Direct Manipulation）

Kindle アプリに準拠した直感的なタッチ操作（スワイプドラッグ・左右タップ・中央タップ）を提供する。

```text
┌────────────────────────────────────────────────────────┐
│                        読書画面                        │
│                                                        │
│  [ 次ページ領域 ]        [ 中央領域 ]    [ 前ページ領域 ] │
│   (左端 約20%)        (オーバーレイ開閉)   (右端 約20%)   │
│                                                        │
│   ← (前へスワイプ)                     (次へスワイプ) → │
│                                                        │
│                                           [ 3 / 12 ]   │
└────────────────────────────────────────────────────────┘
  ※縦書き（右開き・物理メタファー）時の配置
```

1. **ドラッグ中のリアルタイム指追従（Direct Manipulation）**:
   - 水平スワイプ（ドラッグ）操作中、指の移動変位量（`deltaX`）に合わせてページ表示がリアルタイムに 1:1 で水平スライド追従する（CSS `transform: translateX(...)`）。
2. **規定値判定（Threshold）とスナップバック（Snap Back）**:
   - **確定遷移**: ポインターを離した時点で、以下のいずれかを満たす場合に次ページまたは前ページへスムーズにめくりアニメーションを完了する：
     - ドラッグ移動距離が画面幅の **30% 以上**（`Math.abs(deltaX) >= viewportWidth * 0.3`）
     - 素早いフリック操作（フリック速度が一定値以上、推奨 `velocity > 0.5 px/ms`）
   - **スナップバック復帰（キャンセル挙動）**:
     - 移動距離が 30% 未満かつフリック速度も満たさない状態で指を離した場合、ページめくりは行われず、**元のページ位置へ滑らかにバウンス/イージングで引き戻される**（Kindle 同等のキャンセル感）。
3. **縦書き（右開き・物理メタファー）の操作方向**:
   - **左から右（→）スワイプ / ドラッグ**: 「次のページ」（物理の本の紙を右へめくって次を読む感覚）
   - **右から左（←）スワイプ / ドラッグ**: 「前のページ」
   - **画面左端領域タップ（画面幅の約 20%）**: 「次のページ」へ即時めくり（アニメーション付き）
   - **画面右端領域タップ（画面幅の約 20%）**: 「前のページ」へ即時めくり（アニメーション付き）
   - **画面中央領域タップ（幅約 60%）**: 既存の下部オーバーレイ（`ReaderBottomOverlay`）の開閉
4. **横書き（左開き）時の操作方向**:
   - 右から左（←）スワイプ / 画面右端タップ: 「次のページ」
   - 左から右（→）スワイプ / 画面左端タップ: 「前のページ」
   - 画面中央領域タップ: 下部オーバーレイの開閉
5. **タップとドラッグの誤判定防止**:
   - ポインター押下から離上までの移動距離が 10px 未満かつ所要時間が 300ms 未満の操作は「タップ」と判定し、微小な指のブレによる誤ドラッグを防止する。

### 2.4 エピソード端での前後話シームレス遷移（ページめくり ＆ スクロール両対応）

#### A. ページめくりモード時（ラバーバンド抵抗感 ＋ 確定遷移）

- **ラバーバンド（ゴム抵抗感）**:
  - 最終ページでさらに「次のページ」方向へドラッグした際、または第 1 ページでさらに「前のページ」方向へドラッグした際、変位量に減衰係数（例: 変位の $0.3 \sim 0.35$ 倍）を乗算して引っ張られるようなゴム抵抗感を与える。
- **ヒント表示と離上確定**:
  - 引っ張った距離が画面幅の 30% を超えた時点で、画面端に案内バッジ（`data-testid="reader-episode-boundary-hint"`、「指を離して次の話へ」または「指を離して前の話へ」）を表示する。
  - 30% 以上引き伸ばした状態で指を離すと、自動的に次エピソードの第 1 ページ（または前エピソードの最終ページ）へシームレスに遷移する。
  - 30% 未満で指を離した場合は、スナップバックして元のエピソードの端ページに留まる。

#### B. 連続スクロールモード時（誤遷移防止の 2 段階操作）

- 末尾（または先頭）へ向かうスクロールの勢い（慣性や連続ドラッグ）によって最後の文を読み終える前に誤って次の話へ飛んでしまう事故を防ぐため、**2 段階操作** とする：
  1. 第 1 段階: スクロールが末尾（または先頭）に到達した時点では遷移しない。
  2. 第 2 段階: **「一度末尾（または先頭）までスクロールしきった状態から、もう一度同方向へスクロール（スワイプ／ホイール）操作を開始した場合」に限定** して、次の話（または前の話）へ遷移する。

---

### 2.5 端末内しおり進捗率（`0.0〜1.0`）との連動

ページめくりモードとスクロールモードの間で読書位置が相互に矛盾なく復元できるよう、進捗率の計算式を以下の通り統一・連動させる。

1. **ページめくりモード時の進捗率算出**:
   - 総ページ数 $P_{total}$、現在ページ $P_{current}$（1 始まり）のとき：
     $$\text{progress} = \begin{cases} 0.0 & (P_{total} \le 1) \\ \dfrac{P_{current} - 1}{P_{total} - 1} & (P_{total} > 1) \end{cases}$$
   - これにより、第 1 ページは常に `0.0`、最終ページは常に `1.0` となり、スクロールモードの進捗率と 1:1 に整合する。
2. **保存済み進捗率からのページ位置復元**:
   - 保存された進捗率 $R$（`0.0 〜 1.0`）から、該当エピソードのページ数 $P_{total}$ に応じた開始ページを復元する：
     $$P_{restore} = \begin{cases} 1 & (P_{total} \le 1) \\ \text{Math.round}(R \times (P_{total} - 1)) + 1 & (P_{total} > 1) \end{cases}$$
3. **モード切り替え時の位置保持**:
   - 閲覧途中で設定画面からページ送りモードを切り替えても、同一の進捗率を介して適切な読書位置が保たれる。

---

### 2.6 対象外スコープ（今回やらないこと）

- **ハードウェア音量キーによるページ送り（`enable_volume_key_paging`）**: スワイプ＋画面左右タップ操作に集中してシンプルに保ち、音量キー送りは対象外とする。
- **3D カールエフェクト等の過剰な描画エフェクト**: 視認性とパフォーマンスに優れた 2D 横スライドトランジションを採用する。
